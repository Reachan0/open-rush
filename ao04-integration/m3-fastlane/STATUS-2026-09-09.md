## Implemented boundary

`workflow_run` admits `ao04_read_status` only when the composition explicitly
names it. The protected result adapter accepts only an AO-04 `status=ok`
envelope with `data.ready=true`; degraded, cancelled, human-required, malformed,
and transport failures fail the node and preserve completed graph facts.

The protected tool is removed from the outer model catalog, including during a
repair window. It can therefore run only as a fast-lane node. The node calls the
existing AO-04 controller with the current Run lease and operation identity; the
controller owns the real local `tool_app` process and its repair policy.

Both Cordis plugins now fail application when their tool cannot be registered.
They do not leave a running composition that silently lacks M3 protection.
